¿Cómo se ven los badges de ámbito?

Badge "Todo el negocio"
Todo el negocio = professional_id IS NULL
Se muestra cuando el bloqueo aplica a todos los profesionales
Badge "María" / "Carlos" / etc
María = professional_id = 1
Se muestra cuando el bloqueo es solo para un profesional específico

✨ Selector "Todos / María / Carlos / Ana" en vez de dropdown. Filtra qué cards ves. Modo "Todos" muestra bloqueos de cualquier profesional + los generales del negocio. Cada card tiene un badge que indica si es para todo el negocio o para un profesional específico.
