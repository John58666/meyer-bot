📊 Resumen responsive

≥1024px Desktop
  • Side-by-side
  • Calendario 360px
  • Cards flexible
  • Toggle Lista/Grid (-cols-2)
  • Sheet lateral (side)
768-1023px Tablet
  • Calendario arriba (300px)
  • Cards en grid 2 columnas
  • Selectores más compactos
  • Sheet bottom
  • Cards semi compactas
<768px Mobile
  • Todo stacked
  • Calendario full width
  • Cards 1 columna
  • Celdas más pequeñas
  • Sheet bottom
  • Bottom nav

💡 Sidebar pattern con flex-wrap: en desktop el calendario se fija a 360px y las cards ocupan el resto con flex-grow: 999. Cuando la pantalla se achica, todo colapsa naturalmente a stacked sin media queries complejas.
